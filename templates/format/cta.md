# 文末获客 CTA 组件（企微承接 + 双诱饵）

> 用途：注入到每篇公众号文章正文末尾，实现「发文 → 企微承接 → 诱饵发放 → 转化跟进」的获客闭环。
> 通用版：文末获客 CTA 组件模板。二维码取 `config/wecom-qr.png`（放你自己的企微活码）；诱饵钩子请按你的业务改写下方示例文案。

---

## 一、CTA 组件（嵌入正文末尾的最终形态）

> **2026-11-02 改版**：原模板是「AI 量化 / 回复 1/2/3 领资料包」那套，属于投资号时期的残留，
> 跟现在这个号（AI 修炼场，定位是 AI 工具与方法）不搭，且带「免费领取」承诺——没有资料兑现就是虚假承诺。
> 现改为共学邀请型，不做任何承诺。

```markdown
---

想一起学的，后台私信我，我看到就加你。

周末有空，一起聊聊也行。
```

**为什么这么写**：

- 只有一句邀请、一句给出口，不给「好处」，不承诺任何东西
- 用「后台私信」当主路径——公众号天然支持，不依赖二维码或企微
- 不写「长按识别二维码，3 秒添加」这类营销腔，作者的文里一个感叹号都没有，CTA 也不能破这个口吻
- 有微信群二维码时，可在文末另起一段放图，但**不改变上面这段文字**

## 二、占位符说明

| 占位符 | 说明 | 填充方式 |
|--------|------|----------|
| `{{WECOM_QR_IMAGE}}` | 可选：群活码图片 | 默认不用。确有二维码时取 `config/wecom-qr.png`，没有就走「后台私信」，**不阻断发文** |

## 附：更换活码（换码即全链自动复用）

```bash
bash scripts/rotate_wecom_qr.sh <新活码图片路径> [--expires never|YYYY-MM-DD] [--dry-run]
```

- 新活码获取：企业微信后台 →「客户联系 → 加入群聊 → 客户群活码」，一般**长期有效**（`--expires never`）。
- 脚本做三件事：备份旧码 → 覆盖 `config/wecom-qr.png` → 更新 meta 与台账。
- **format 只认固定路径**，换码后无需改文章、模板或脚本。

---

## 三、注入规则（format 环节强制）

1. **注入位置**：正文「风险提示」之后、文章最末尾。
2. **注入条件**：QA 质检 ≥80 分且已过审的文章，全部注入（获客是每篇的固定收尾）。
3. **二维码处理（活码自动复用）**：
   - format **只认固定路径** `config/wecom-qr.png`：只要该文件存在，就作为配图插入，并随其他配图一起走 `scripts/compress_image.sh` 压缩。
   - 因此**换码无需改任何文章/模板**：把新活码覆盖 `config/wecom-qr.png` 即可，format 下次跑自动用新码（建议跑 `scripts/rotate_wecom_qr.sh` 同步 meta 与台账）。
   - 若缺失 → 用文字引导「微信搜索：<config.wechat_account_name>」替代，**不阻断发文**，但需在 `04_publish_queue.md` 备注栏标记「待补二维码」。
4. **有效期感知**：format 启动时读 `config/wecom-qr.meta.json`；若 `never_expires=true` 直接复用；若已过期或 3 天内到期，则在 `04_publish_queue.md` 备注栏标记「二维码待更换」，并提醒主控更新。
5. **一句话校验**：注入后正文末尾必须含「私信」或「加你」，否则视为注入失败，打回 format 重做。

## 四、话术库（可复用，随 RSI 台账迭代）

| 场景 | 话术 |
|------|------|
| 主用（共学邀请） | 「想一起学的，后台私信我，我看到就加你。」 |
| 加一句时间钩子 | 「周末有空，一起聊聊也行。」 |
| 有群时的补充 | 「群里每天有人问问题，想进的说一声。」（不写二维码就不放图） |
| 兜底文字 | 「微信搜索：<config.wechat_account_name>，后台留言。」 |

**不再使用的旧话术**（2026-11-02 起停用，留档说明原因）：

| 停用 | 原因 |
|------|------|
| 「👇 长按识别二维码，3 秒添加」 | 营销腔。作者全文零感叹号，CTA 破口吻 |
| 「回复【1】领取《…资料包》」 | **没有资料就是虚假承诺**，且属于投资号时期的残留 |
| 「预约一对一诊断」 | 他没有这项服务，不能写 |

> 话术随人工修正记录进 `_rsi_ledger.md`「金句库」，不断迭代。
